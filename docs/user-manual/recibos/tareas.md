# Tareas de Recibos

## Descargar recibo de un pago

1. Menú → Pagos → abre el pago aplicado.
2. En el panel lateral, busca el bloque "Recibo".
3. Usa:
    - PDF: descarga el comprobante en formato PDF.
    - Verificar: abre un enlace firmado para validación pública del recibo.

## Descargar recibos por cargo

1. En el detalle del pago, sección "Recibos por cargo".
2. Usa los enlaces PDF/Verificar por cada fila para descargar y validar.

## Recibos en el Portal

- Portal → Mis recibos: lista de los últimos recibos con descarga PDF.
- También puedes navegar desde Portal → Aplicar pago (al finalizar, verás acceso directo a recibos).

## Consejos

- Si no ves el recibo del pago: revisa que el pago esté en estado APPLIED.
- Si no ves un recibo por cargo: revisa la sección "Asignaciones" del pago; si no hubo aplicación a ese cargo en particular, no se emite recibo por cargo.
