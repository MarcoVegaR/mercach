# FAQ del Portal

## El banco rechazó mi pago (p. ej., 706)

- El sistema muestra el mensaje exacto del banco y preserva tus datos. Corrige el campo indicado (cuenta, teléfono, referencia, monto o fecha) y reintenta.

## No veo mis cargos para aplicar

- Verifica filtros (moneda, tipo, periodo, “solo vencidos”).
- Si cambiaste de contrato/local recientemente, puede que algunos cargos estén asociados a locales anteriores. Aplica filtros amplios primero.

## El equivalente en Bs no aparece

- Si el cargo no tiene monto Bs emitido, el sistema calcula con la tasa vigente a la fecha de pago. Si no hay tasa para ese día, intenta otra fecha cercana.

## No puedo aplicar todo el monto

- Revisa el disponible del pago y si tienes crédito a favor. No puedes exceder el saldo del cargo ni el disponible (pago + crédito si activas “usar crédito”).

## ¿Puedo deshacer una aplicación?

- Contacta a soporte. Las aplicaciones afectan históricos y recibos; se requiere revisión para revertir.

## ¿Qué métodos de pago acepta el Portal?

- Transferencia y Pago Móvil. Otros métodos (p. ej., débito) se gestionan por taquilla/administración.
