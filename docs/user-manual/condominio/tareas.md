# Tareas de Condominio

## Crear o actualizar un período

1. Menú → Condominio → Períodos.
2. En “Crear período”, elige Mercado y Periodo (YYYY-MM). Guarda. Se abrirá el workspace.

## Cargar gastos del período (USD)

1. En la pestaña Gastos, usa “Agregar” para cada gasto. Completa tipo, descripción y monto USD.
2. Puedes usar “Carga masiva” si tienes varios ítems.
3. Verifica el total USD en el resumen.

## Definir participantes (locales incluidos/excluidos)

1. En la pestaña Participantes, usa “Sembrar participantes” o “Incluir/Excluir masivo por filtro”.
2. Excluye locales puntuales cuando aplique. Asegúrate de que la suma de m² sea > 0.

## Confirmar período a FINAL

1. Revisa que Gastos > 0 y hay participantes válidos.
2. Pulsa “Confirmar a FINAL”. Desde aquí, el período queda listo para generar cargos de condominio.

## Reabrir para corregir

- Si necesitas ajustes, usa “Reabrir a DRAFT”, realiza correcciones y vuelve a FINAL.

## Generar cargos (desde Cargos → Ejecutar)

- En Cargos → Ejecutar, selecciona tipo “CONDO_USD”, Mercado y Periodo. Se validará que el período esté FINAL, que tenga gastos y participantes válidos.
