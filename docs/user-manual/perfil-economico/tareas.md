# Tareas del Perfil económico

## Buscar por Concesionario

1. Menú → Administración → Perfil Económico.
2. En "Concesionario", escribe nombre o documento.
3. Selecciona el resultado. Verás:
    - Deuda abierta (ISSUED/PARTIAL) con equivalentes a Bs cuando aplique.
    - Créditos disponibles (saldo a favor).
    - Pagos recientes.
    - Recibos.

## Buscar por Local

1. En el mismo buscador, cambia a "Local".
2. Escribe el código del local (por ejemplo, M-012).
3. Selecciona el resultado para ver su situación económica.

## Exportar a CSV

- Usa el botón "Exportar" para descargar un CSV de la vista actual.

## Consejos

- Si el concesionario tiene múltiples contratos/locales, los totales consolidan la deuda abierta.
- Para deudas muy antiguas, aplica filtros de periodo si están disponibles en la vista.
