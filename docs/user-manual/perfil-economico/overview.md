# Perfil económico — Visión general

- Ubicación: Administración → Perfil Económico.
- Búsqueda:
    - Por Concesionario (nombre o documento).
    - Por Local (código).
- Resultados: resumen de deuda abierta (ISSUED/PARTIAL), crédito disponible, pagos recientes y recibos.
- Acciones:
    - Exportar a CSV.
    - Abrir detalles por ítem (cuando aplique).
- Permisos: requiere `admin.economic_profile.view` (y `export` para CSV).
