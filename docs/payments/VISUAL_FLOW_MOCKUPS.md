## Leyenda de símbolos

| Símbolo | Significado                      |
| ------- | -------------------------------- |
| ✓ / ✅  | Completado, verificado, OK       |
| ⏱ / ⏳ | Pendiente, en proceso            |
| ⚠️      | Advertencia, atención            |
| 🔴      | Vencido, urgente                 |
| ❌      | Error, cancelado                 |
| ✨      | Destacado, recomendado           |
| ℹ️      | Información                      |
| ☑️      | Seleccionado (checkbox marcado)  |
| ☐       | No seleccionado (checkbox vacío) |
| 🟢      | Acción positiva (botón verde)    |
| →       | Flujo, siguiente paso            |
| ━━━━    | Paso activo (destacado)          |
| ────    | Paso completado o pendiente      |
| ▓       | Barra de progreso (lleno)        |
| ░       | Barra de progreso (vacío)        |

## Notas de diseño

### Colores por contexto

| Contexto      | Color              | Uso                                                  |
| ------------- | ------------------ | ---------------------------------------------------- |
| Éxito         | Verde (#22c55e)    | Botones primarios, confirmaciones, pagos verificados |
| Información   | Azul (#3b82f6)     | Resúmenes, estado normal, pasos activos              |
| Advertencia   | Amarillo (#eab308) | Pendientes, en verificación                          |
| Error/Urgente | Rojo (#ef4444)     | Deudas vencidas, errores                             |
| Neutro        | Gris (#6b7280)     | Información secundaria                               |

### Espaciado y tipografía

- **Títulos principales**: 24-32px, bold
- **Subtítulos**: 16-18px, semibold
- **Texto normal**: 14px, regular
- **Texto pequeño**: 12px, regular (fechas, descripciones)
- **Espaciado entre secciones**: 24-32px
- **Padding interno cards**: 16-24px
- **Bordes**: 1px, redondeados (8px radius)

### Responsive

- **Desktop** (> 1024px): 2 columnas (content + sidebar)
- **Tablet** (768-1023px): 1 columna, sidebar abajo
- **Mobile** (< 768px): 1 columna, stack vertical, botones full-width
